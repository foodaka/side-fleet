Connect your first machine

1

Pick a machine that already has Claude Code installed and signed in and your repos checked out. Your laptop is fine. It needs no open ports, only a way to reach this page's address.

Check with claude --version on that machine.
2

Install Sidefleet there (one line, no sudo):

curl -fsSL https://raw.githubusercontent.com/foodaka/side-fleet/main/install.sh | sh
3

Connect it to this control plane. The token is filled in below. This checks Claude Code, registers the machine and installs a background service so it stays connected after a reboot.

sidefleet connect --control … --token …
If this page's address is only reachable from this machine, use the control plane's Tailscale or LAN address instead of . Add --repos ~/Projects if your repos are not under ~/Code.

Or let an agent do steps 2 and 3. Paste this into Claude Code on that machine; it reads /connect.md and does the install and connect for you.

4

Watch it appear. The worker checks Claude Code, Codex and Ollama, scans your repos, and registers within a few seconds.
